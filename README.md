# Конфигурация Neovim

Личная конфигурация Neovim с деревом файлов и Git-статусом слева и файловыми вкладками над окнами редактора.

## Установка и запуск

Конфигурация проверена с Neovim 0.12.6. Для установки плагинов нужны Git в `PATH` и доступ к GitHub.

Разместите репозиторий в каталоге конфигурации Neovim (`~/.config/nvim` по умолчанию на macOS). При первом запуске `vim.pack` установит недостающие плагины.

Запустите Neovim из корня рабочего Git-репозитория.

```sh
nvim .
```

Слева откроется Explorer с деревом файлов. Справа появится окно редактора.

## Переключение вкладок

Нажмите Git левой кнопкой мыши, чтобы открыть статус Fugitive. Нажмите Explorer, чтобы вернуться к дереву. При переключении правые окна сохраняют расположение, размеры, открытые буферы, положение курсора, прокрутку и несохранённые изменения.

В статусе Fugitive нажмите `=` на изменённом файле, чтобы раскрыть diff прямо в панели. Клавиши `s` и `u` добавляют в индекс и убирают из него файл или фрагмент под курсором.

| Действие | Результат |
| --- | --- |
| Option+F | Переводит фокус на активную вкладку левой панели. Если панель закрыта, открывает Explorer. |
| Option+G | Возвращает фокус в последнее доступное окно редактора на текущей странице. |
| Option+1 или Option+2 в левой панели | Выбирает Explorer или Git соответственно. |
| Option+1…Option+0 в редакторе | Выбирает файловую вкладку по порядку. Option+0 выбирает десятую. |
| Option+W в редакторе | Закрывает текущую файловую вкладку и сохраняет окно. |
| `:AtlzTabNext` или `:AtlzTabPrev` в левой панели | Переключает Explorer и Git. |
| `:AtlzTabNext` или `:AtlzTabPrev` в редакторе | Выбирает следующий или предыдущий файловый буфер. |
| `:AtlzTabClose` в редакторе | Закрывает текущую файловую вкладку и сохраняет окно редактора. |

Клик по файловой вкладке открывает буфер в окне под ней. Полоса выделяет активную вкладку и помечает несохранённые изменения значком `[+]`. Если вкладка скрылась из-за ширины окна, выберите буфер командой `:buffer` в правом окне.
Сочетания Option работают в обычном режиме. Нумерация файловых вкладок учитывает вкладки, скрытые в узком окне.

При закрытии последней файловой вкладки в окне редактора остаётся пустой буфер. Если файл изменён, сохраните его командой `:w` перед закрытием.
Чтобы закрыть файл и отбросить несохранённые изменения, выполните `:AtlzTabClose!`. Explorer и Git остаются открытыми при вызове `:AtlzTabClose` из левой панели.

Встроенные `:bnext`, `:bprev` и `:bdelete` работают по правилам Neovim. Для закрытия файла с сохранением окна используйте `:AtlzTabClose`.

## Если Git или мышь недоступны

- Вкладка Git использует рабочий каталог окна редактора. Открывайте Neovim из рабочего дерева Git.
- Если статус Fugitive для этого репозитория уже открыт в другом сплите текущей вкладки Neovim, панель вернётся к Explorer. Закройте отдельный статус, чтобы открыть его в панели.
- Для кликов опция `mouse` в Neovim должна быть включена для текущего режима. В iTerm2 включите **Enable mouse reporting** и **Report mouse clicks & drags** в **Settings → Profiles → Terminal** для активного профиля. [Документация iTerm2](https://iterm2.com/documentation-preferences-profiles-terminal.html)

## Конфигурация панелей

[Модуль раскладки](lua/workspace.lua) рисует полосы вкладок через оконный `winbar`. Explorer использует nvim-tree, а Git открывает Fugitive командой `:Git ++curwin` в левом окне. Положение курсора в статусе может сбрасываться при повторном открытии. NeoGit можно открыть отдельно командой `:Neogit`.

Полосы используют стандартные группы выделения Neovim в цветовой схеме Noirbuddy.
