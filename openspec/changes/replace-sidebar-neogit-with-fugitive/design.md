# Design

## Context

`lua/workspace.lua` выделяет левый сплит, открывает в нём статус Neogit и восстанавливает размеры и прокрутку правых окон после переключения. Вкладки Explorer и Git рисуются в оконном `winbar`. Мотивация описана в [предложении](proposal.md).

## Goals / Non-Goals

Использовать существующий жизненный цикл левой панели, чтобы Fugitive управлял содержимым Git-статуса, а модуль раскладки управлял окном и переключением вкладок. Область интеграции ограничена статусом в левой панели. Самостоятельные команды Git и управление правыми файловыми вкладками сохраняют свои интерфейсы.

## Decisions

- **Запускать Fugitive в выделенном окне.** Получить рабочий каталог правого редактора до перехода в левый сплит, проверить, что это рабочее дерево Git, и установить этот каталог локально в новом левом окне через `:lcd`. Вызвать `:Git ++curwin` из его пустого буфера. Fugitive определяет репозиторий по каталогу такого окна и открывает статус через `:edit`. Команда `:vertical Git` тоже размещает статус в сплите, но выделяет окно сама. Здесь его шириной и жизненным циклом уже управляет конфигурация. [Определение репозитория](https://github.com/tpope/vim-fugitive/blob/master/plugin/fugitive.vim#L18-L32) · [Открытие статуса](https://github.com/tpope/vim-fugitive/blob/master/autoload/fugitive.vim#L4197-L4227)
- **Проверять окно и буфер после открытия.** Считать вкладку Git активной, когда выделенный левый сплит показывает буфер статуса Fugitive. Использовать тип файла и признак статуса окна, чтобы отличать его от других буферов Fugitive. Только после проверки сохранить окно в состоянии раскладки и установить `winbar`.
- **Сохранить текущий механизм восстановления правых сплитов.** Перед переключением запомнить размеры и вид каждого правого окна, временно отключить автоматическое выравнивание и восстановить параметры после смены левого сплита. Переходы по мыши и клавиатуре используют тот же путь переключения. Буфер статуса Fugitive имеет тип `nowrite` и исключается существующим фильтром правых файловых вкладок. [Инициализация буфера статуса](https://github.com/tpope/vim-fugitive/blob/master/autoload/fugitive.vim#L3063-L3086)

## Risks / Trade-offs

- **Статус того же репозитория уже открыт в другом сплите текущей вкладки.** Fugitive может перевести туда фокус. Если статус не появился в выделенном окне, закрыть временный сплит, восстановить Explorer, вернуть фокус в рабочую раскладку и сообщить причину. Уже открытое окно статуса остаётся доступным.
- **Переключение при открытом diff.** При проверке использовать правые сплиты с включённым diff, чтобы подтвердить сохранение их буферов, размеров и режима.

## Migration Plan

Добавить `tpope/vim-fugitive` через `vim.pack`, обновить lock-файл, подключить Fugitive к вкладке Git и обновить README. На время пробы сохранить установленный Neogit и его самостоятельную команду `:Neogit`. Для отката достаточно вернуть открытие Neogit в левой панели.
