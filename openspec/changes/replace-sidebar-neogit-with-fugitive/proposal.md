# Proposal

## Why

Вкладка Git слева уже даёт доступ к состоянию репозитория рядом с редактором. Fugitive позволит попробовать в этой вкладке просмотр diff и работу с индексом прямо в списке изменений, сохранив привычную раскладку.

## What Changes

- Открывать интерактивный статус `vim-fugitive` во вкладке Git существующей левой панели.
- При переключении между Explorer и Git сохранять расположение и размеры правых сплитов, открытые буферы, курсоры, прокрутку и несохранённые правки.
- Сохранить выбор вкладок мышью и существующие клавиатурные переходы.

## Impact

- Подключение Fugitive через `vim.pack` и обновление записи о зависимостях.
- Обновление модуля раскладки и инструкции по использованию левой панели.
- Самостоятельная команда `:Neogit` остаётся доступной на время пробы. `:AtlzGitDiff` продолжает пользоваться Gitsigns.
