# Spec Delta

## MODIFIED Requirements

### Requirement: Вкладки левой панели

Рабочая раскладка SHALL показывать слева вкладки Explorer с nvim-tree и Git с интерактивным статусом Fugitive. Левая кнопка мыши SHALL выбирать вкладку, а панель SHALL отмечать активную вкладку и показывать её содержимое.

#### Scenario: Начальная раскладка

- **WHEN** пользователь запускает Neovim с обычным файлом
- **THEN** слева активна Explorer и видно дерево файлов
- **AND** файл открыт в редакторе справа

#### Scenario: Переключение мышью

- **WHEN** пользователь нажимает левой кнопкой мыши Git в рабочей раскладке Git-репозитория
- **THEN** на текущей странице Neovim слева отображается статус Fugitive для рабочего каталога окна редактора, а Git отмечена как активная вкладка
- **AND** последующий клик по Explorer возвращает дерево в левую панель

#### Scenario: Чистое рабочее дерево

- **WHEN** пользователь выбирает Git в репозитории без незакоммиченных изменений
- **THEN** слева открывается статус Fugitive с информацией о чистом рабочем дереве, а Git отмечена как активная вкладка

#### Scenario: Git недоступен для рабочего каталога

- **WHEN** пользователь выбирает Git вне рабочего дерева Git
- **THEN** Neovim сообщает, что Git-статус недоступен, и оставляет Explorer доступным
- **AND** репозиторий не создаётся и редактор остаётся доступным

### Requirement: Состояние редактора при переключении панели

Переключение Explorer и Git SHALL сохранять список открытых файлов и правые окна с их расположением, размерами, текущими буферами, курсорами и прокруткой. Изменённые буферы SHALL сохранять содержимое и признак несохранённых изменений.

#### Scenario: Переключение с изменённым файлом и правыми сплитами

- **GIVEN** в правых сплитах открыты два файла, один из которых изменён и ещё не сохранён
- **WHEN** пользователь несколько раз переключает Explorer ↔ Git левой кнопкой мыши
- **THEN** оба правых окна сохраняют расположение, размеры, файлы, позиции курсоров и прокрутку на каждом переключении
- **AND** изменённый текст остаётся в памяти с признаком несохранённых изменений, а файл на диске сохраняет прежнее содержимое

### Requirement: Переход к панели и редактору с клавиатуры

Option+F SHALL переводить фокус на активную вкладку левой панели, сохраняя её содержимое. Если панель закрыта, Option+F SHALL открыть Explorer. Option+G SHALL возвращать фокус в последнее доступное окно редактора на текущей странице.

#### Scenario: Возврат к редактору из боковой панели

- **GIVEN** слева активна Git, а фокус находится в редакторе
- **WHEN** пользователь нажимает Option+F
- **THEN** фокус переходит в существующее окно Git, сохраняя его буфер и курсор
- **AND** последующее нажатие Option+G возвращает фокус в редактор, а слева остаётся Git

#### Scenario: Фокус при закрытой панели

- **WHEN** пользователь нажимает Option+F при закрытой левой панели
- **THEN** слева открывается Explorer и получает фокус
