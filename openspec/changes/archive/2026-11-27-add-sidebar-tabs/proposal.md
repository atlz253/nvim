# Proposal

## Why

nvim-tree уже открывается слева, а Neogit по умолчанию открывает отдельную страницу Neovim. Единая рабочая раскладка позволит просматривать файлы и Git-статус рядом с редактором и сохранять контекст работы при переключении.

## What Changes

- Добавить в левую панель вкладки Explorer (nvim-tree) и Git (Neogit). При запуске активна Explorer.
- Показать над правой областью вкладки открытых файлов с отметкой активного буфера и несохранённых изменений.
- Поддержать выбор вкладок обеих панелей левой кнопкой мыши. Переключение Explorer ↔ Git сохраняет открытые файлы и состояние правых окон.
- Описать устройство панелей, управление и ограничения в документации конфигурации.

## Capabilities

### New Capabilities

- `sidebar-tabs` — независимое переключение Explorer и Git, выбор файловых буферов справа и сохранение состояния редактора.

### Modified Capabilities

## Impact

- Затрагивает запуск панели в `lua/autostart.lua`, привязки фокуса в `lua/hotkeys.lua` и новый модуль раскладки.
- Использует нативный интерфейс Neovim и публичные API установленных nvim-tree и Neogit. Сохраняет `vim.pack`, Noirbuddy, существующие команды и назначения горячих клавиш.
