# Spec Delta

## Purpose

Дать доступ к дереву файлов и Git-статусу рядом с редактором и позволить переключаться между ними, сохраняя состояние открытых файлов.

## ADDED Requirements

### Requirement: Вкладки левой панели

Рабочая раскладка SHALL показывать слева вкладки Explorer с nvim-tree и Git с Neogit. Левая кнопка мыши SHALL выбирать вкладку, а панель SHALL отмечать активную вкладку и показывать её содержимое.

#### Scenario: Начальная раскладка

- **WHEN** пользователь запускает Neovim с обычным файлом
- **THEN** слева активна Explorer и видно дерево файлов
- **AND** файл открыт в редакторе справа

#### Scenario: Переключение мышью

- **WHEN** пользователь нажимает левой кнопкой мыши Git в рабочей раскладке Git-репозитория
- **THEN** на текущей странице Neovim слева отображается Git-статус, а Git отмечена как активная вкладка
- **AND** последующий клик по Explorer возвращает дерево в левую панель

#### Scenario: Git недоступен для рабочего каталога

- **WHEN** пользователь выбирает Git вне рабочего дерева Git
- **THEN** Neovim сообщает, что Git-статус недоступен, и оставляет Explorer доступным
- **AND** репозиторий не создаётся и редактор остаётся доступным

### Requirement: Состояние редактора при переключении панели

Переключение Explorer и Git SHALL сохранять список открытых файлов и правые окна с их текущими буферами, курсором и прокруткой. Изменённые буферы SHALL сохранять содержимое и признак несохранённых изменений.

#### Scenario: Переключение с изменённым файлом и правыми сплитами

- **GIVEN** в правых сплитах открыты два файла, один из которых изменён и ещё не сохранён
- **WHEN** пользователь несколько раз переключает Explorer ↔ Git левой кнопкой мыши
- **THEN** оба правых окна остаются на своих файлах с прежними положениями курсоров и прокрутки
- **AND** изменённый текст остаётся в памяти и файл на диске сохраняет прежнее содержимое

### Requirement: Вкладки файловых буферов

Правая область SHALL показывать вкладки файловых буферов, отмечать текущий файл и несохранённые изменения. Клик левой кнопкой мыши SHALL показывать выбранный буфер в правом окне редактора.

#### Scenario: Выбор файла при фокусе слева

- **GIVEN** справа доступны две файловые вкладки, а фокус находится в Explorer или Git
- **WHEN** пользователь нажимает правую файловую вкладку левой кнопкой мыши
- **THEN** файл отображается в правом окне с фокусом и активной отметкой вкладки
- **AND** режим и содержимое левой панели сохраняются

### Requirement: Переход к панели и редактору с клавиатуры

Существующие сочетания Option+F и Option+G SHALL сохранять назначение перехода к Explorer и редактору соответственно.

#### Scenario: Возврат к редактору из боковой панели

- **WHEN** пользователь нажимает Option+F при открытой вкладке Git, а затем Option+G
- **THEN** первое сочетание показывает Explorer и переводит туда фокус, а второе возвращает фокус в редактор
